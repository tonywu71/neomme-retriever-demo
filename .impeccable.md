## Design Context

### Users

The primary visitors are machine learning researchers and engineers evaluating NeoMME. They need to upload a document, run retrieval, and see convincing results with little setup.

### Brand Personality

The interface should feel academic, careful, and direct. It should present NeoMME as serious research software without looking like a benchmark dashboard or a generic product landing page.

### Aesthetic Direction

Keep the existing editorial academic identity. Use the paper-toned palette, restrained oxblood accent, display sans headings, and readable serif body text. Improve hierarchy and task flow without replacing the visual character.

### Design Principles

1. Make the upload, index, query, and retrieval sequence obvious at a glance.
2. Keep model and scoring choices available without letting them dominate the main task.
3. Show progress and invalid state changes where the user acts.
4. Keep research details close to the controls they explain.
5. Preserve keyboard access, visible focus, readable contrast, and useful mobile layouts.
